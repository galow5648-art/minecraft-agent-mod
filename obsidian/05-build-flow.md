# Обновление и сборка

1. Закрыть Minecraft (jar заблокирован, пока игра запущена).
2. Запустить `update.cmd` с рабочего стола.
3. Ответить `y` на «Reinstall anyway?», нажать Enter.
4. Дождаться сборки; `build.bat` кладёт jar в `game\mods` и удаляет старые версии мода.
5. Перезапустить приложение Claude, зайти в мир, вызвать инструменты.

Скрипт: `scripts/update.cmd` в репозитории. ZIP берётся из `main`.

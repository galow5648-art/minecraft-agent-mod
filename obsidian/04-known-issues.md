# Известные проблемы и непроверенное

- `/goto` теперь на A*; после сборки проверить в игре: ступени и плиты считаются полными блоками, вода обходится, плавание не реализовано.
- Не проверено в игре (код написан без сборки): `/find`, `/surroundings`, `/open`, `/menu`, `/click`, `/close`, `/select_tool`, отключение паузы при потере фокуса (рефлексия по полю `pauseOnLostFocus`), `ItemStack.getDestroySpeed`, `Player.closeContainer`.
- При ошибке компиляции после `build.bat` прислать вывод: имена методов 26.3 могли отличаться.
- `minecraft_smelt`, `minecraft_dig_to`, автокрафт через верстак проверены только на поддельном API (логика), не в игре.
- Подбор предметов с земли: предметы остаются на земле, если их не пройти.
- Крафт по шаблонам (`/craft`) не проверен в игре.
- Листва в кроне: сложно спуститься к земле через `/goto` без `break`.
- Сборка не проверяется в облаке: Maven недоступен. Ошибки компиляции видны только после `build.bat`.
- MCP-сервер и мод обновляются вместе через `update.cmd`; без перезапуска приложения Claude новые инструменты не видны.

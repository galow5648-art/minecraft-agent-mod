# minecraft-agent-mod

Проект: Fabric-мод для Minecraft 26.3, который открывает локальный API, чтобы ИИ-агент мог управлять персонажем в одиночной игре (движение, взгляд, добыча блоков, крафт, чтение инвентаря).

## Структура
- `mod/` — исходный код мода (будет добавлен).
- `README.md` — описание проекта.

## Статус
Черновик. Сейчас создана структура репозитория.
